# Synchronous-Fine-Motor-Model
Uses feedback to adjust the PWM selection of units operating in tandem.

### Overview
Test the ability of an MCU to adequately vary a single motor's speed based upon the group output.

### Problem
Uneven distribution of parallel motor wear due to imbalanced load distribution. 

### Equipment Used
- Arduino Uno
- 2x small DC motor
- LC39D motor driver IC
- Breadboard/Wires

### Setup
1. Wire the two motors to the IC IAW the schematic
2. Wire the output to the Arduino
3. Upload the driver code

Contribution: Circuit setup and debugging
